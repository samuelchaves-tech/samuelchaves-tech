## 🚀 Sobre mim

Desenvolvedor Full Stack formado em Análise e Desenvolvimento de Sistemas pela Universidade Católica de Brasília.

Tenho experiência prática no desenvolvimento de aplicações web, APIs REST e interfaces responsivas utilizando tecnologias como React.js, Node.js, JavaScript e PostgreSQL.

Atuo no desenvolvimento de projetos reais voltados a sistemas internos e websites institucionais, buscando sempre escrever código organizado, criar interfaces modernas e evoluir tecnicamente em desenvolvimento web.

Atualmente foco meus estudos e projetos em:
- Desenvolvimento Full Stack
- APIs REST
- React.js e Node.js
- Banco de dados PostgreSQL
- Estruturação de aplicações web modernas
