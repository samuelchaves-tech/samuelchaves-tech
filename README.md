# 👨‍💻 Sobre mim

Sou Tecnólogo em **Análise e Desenvolvimento de Sistemas** pela Universidade Católica de Brasília, direcionando minha carreira para as áreas de **Suporte Técnico, Service Desk, Infraestrutura de TI, Redes e Segurança da Informação**.

Tenho conhecimentos práticos em **Windows, Windows Server, Linux, Active Directory, Redes TCP/IP, DNS, DHCP, Virtualização, Microsoft 365, Microsoft Teams, Hardware, SQL e Git/GitHub**, desenvolvidos por meio de cursos, laboratórios e projetos práticos.

Também possuo conhecimentos em desenvolvimento de software, permitindo compreender melhor aplicações, bancos de dados e ambientes corporativos.

Atualmente estou construindo laboratórios práticos e projetos para fortalecer minhas habilidades em infraestrutura e administração de ambientes Windows e Linux.
